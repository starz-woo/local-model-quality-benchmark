# agent.py — 사용자 제공 독립 에이전트 실험

`agent.py`는 사용자가 제공한 Python 소스를 수정하지 않고 추가한 파일입니다.
Claude Code나 Codex CLI를 실행하는 래퍼가 아니라 OpenAI 호환 API를 직접 호출하는 별도 에이전트입니다.
기존 `bench.py`·`agent_runner.py`와 연결되지 않으며, 이 파일을 추가해도 기존 실행 경로는 바뀌지 않습니다.
MD-only 지침 배포 변경(PR #8)과도 별개입니다.

## 실행 전 확인

- Python 3.10 이상이 필요합니다. Windows에서는 `py` 대신 `python`을 사용하면 됩니다.
- 이 파일은 기존 벤치마크와 달리 `openai`, `rich`, `duckduckgo-search` 패키지가 필요합니다.
- **실행뿐 아니라 import 시에도** 누락된 패키지를 `sys.executable -m pip install`로 자동 설치합니다.
  현재 Python 환경을 바꾸므로 별도 가상환경을 사용하세요. pip가 없거나 네트워크가 차단되면 실패할 수 있습니다.
- 코드 상단 `MODEL_NAME` 기본값은 `qwen2.5-coder:7b`, `BASE_URL`은 `http://localhost:11434/v1`입니다.
  실제 제공 중인 모델·OpenAI 호환 서버 주소에 맞게 직접 수정해야 합니다.
- CC Switch의 Claude Code 설정·모델 별칭·인증은 자동 상속하지 않습니다.
- `api_key="local-key"`는 로컬 서버용 자리표시자입니다. 인증이 필요한 서버에는 별도 구성이 필요하며 실제 비밀을 Git에 커밋하지 마세요.

검토한 서버와 폐기 가능한 작업 디렉터리에서 파일의 실제 경로를 지정해 실행합니다.
아래 명령은 패키지 설치와 대화형 모델 호출이 가능한 **실제 실행**입니다.

```powershell
python C:/path/to/local-model-quality-benchmark/agent.py
```

현재 작업 디렉터리가 파일 도구의 상대 경로 기준입니다. `/clear`는 대화 기록 초기화,
`/tree`는 현재 디렉터리 목록, `/exit`는 종료입니다.

## 원본 동작과 알려진 한계

이 파일은 원본 보존 목적으로 추가했습니다. 아래 항목을 수정·해결한 버전은 아닙니다.

- 배너의 `KV Cache: Active`는 고정 문자열입니다. 서버의 캐시 적중을 확인한 결과가 아닙니다.
- `cache_prompt: True`는 모든 OpenAI 호환 서버의 공통 설정이 아닙니다. 서버에 따라 무시되거나 요청이 거부될 수 있습니다.
  고정 시스템 프롬프트만으로 KV 캐시 활성화·속도 개선을 보장하지 않습니다.
- 수정과 셸 실행 전에 y/n 승인을 요청하지만 **OS 샌드박스나 작업 경로 제한은 없습니다.** 읽기는 승인 없이 수행하며,
  절대 경로·상위 경로에도 접근할 수 있습니다. 민감한 파일이 있는 환경에서 실행하지 마세요.
- `<bash>`는 `shell=True`로 실행됩니다. Windows 기본 셸은 일반적으로 cmd.exe이며 Bash/PowerShell과 동일하지 않습니다.
  승인한 명령은 사용자 권한으로 실행됩니다. 웹·모델 출력 속 지시를 신뢰하지 마세요.
- 셸 결과는 끝부분으로 잘리고 종료 코드가 모델에 별도로 전달되지 않습니다. 비정상 종료라도 성공처럼 해석될 수 있습니다.
  20초 제한은 자식 프로세스 트리 전체 종료를 보장하지 않습니다.
- 기존 파일에 SEARCH 블록이 없는 edit를 승인하면 파일 전체를 덮어쓸 수 있습니다.
  공백 정리·첫 번째 일치 교체·구분자 파싱 한계가 있으므로 미리보기와 실제 diff를 검토하세요.
- 한 응답 한 도구 호출은 프롬프트 지침입니다. 파서는 여러 태그를 거부하지 않고 정해진 우선순위의 첫 일치를 실행합니다.
- 출력 토큰 상한과 종료 태그 복원은 완전한 코드·패치·명령을 보장하지 않습니다.
- 단계 제한은 있지만 누적 대화의 토큰 예산·장기 컨텍스트 압축·독립 기능 채점은 없습니다.
- 웹 검색은 외부 서비스로 쿼리를 전송합니다. 서버·검색·패키지 설치를 포함한 네트워크 사용을 검토하세요.

## 검사 범위

```powershell
python scripts/run_tests.py
```

이 명령은 저장소 루트에서 실행합니다. `test_agent.py`는 의존성·UI·API 클라이언트를 모킹한 뒤 소스를 로드합니다.
자동 설치는 차단하며 모델·검색·셸을 호출하지 않습니다. 실제 임시 파일 생성/읽기/SEARCH-REPLACE/거부,
시스템 메시지 유지·초기화, 반복 상한과 셸 승인 거부를 검사합니다.
구문 검사와 이런 오프라인 동작 검사는 실제 모델 연결·Windows 실행·검색 호환성·캐시 적중·성능을 검증하지 않습니다.
